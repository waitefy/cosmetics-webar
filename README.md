# WebAR-лендинг для бренда косметики с визуализацией продукции

Курсовая работа по дисциплине «Разработка кроссплатформенных приложений дополненной реальности».

Федеральное государственное бюджетное образовательное учреждение высшего образования «МИРЭА – Российский технологический университет». Институт информационных технологий, кафедра игровой индустрии.

Посетитель открывает карточку помады «Мягкий цвет», выбирает один из восьми оттенков и видит, как меняется цвет стика. Розовый и ягодный оттенки взяты из демонстрационного каталога учебной практики.

## Запуск

Открыть [лендинг на GitHub Pages](https://waitefy.github.io/cosmetics-webar/) в браузере телефона или компьютера.

Для локального запуска выполнить из корня проекта команды:

```sh
npm ci
npm run dev
```

Открыть [localhost:5173/cosmetics-webar/](http://localhost:5173/cosmetics-webar/).

## Стек

TypeScript, HTML и CSS. Vite запускает сервер разработки и собирает сайт. GitHub Actions проверяет типы, запускает сборку при обновлении ветки `main` и публикует результат на GitHub Pages. Для примерки MediaPipe определяет контуры губ, а Canvas 2D накладывает выбранный оттенок. [MediaPipe Face Landmarker](https://developers.google.com/edge/mediapipe/solutions/vision/face_landmarker).

## Состояние

В карточке товара можно выбрать оттенок и посмотреть помаду на снимках с трёх ракурсов. В 3D можно вращать упаковку, снимать и надевать колпачок, выкручивать и вкручивать стик.

Кнопка «Примерить оттенок» включает фронтальную камеру после разрешения браузера. Кнопка с разделёнными губами открывает сравнение. Первая палитра управляет оттенком слева, вторая — оттенком справа. Границу между ними можно перетаскивать мышью или пальцем и перемещать стрелками с клавиатуры. В обеих палитрах перечёркнутый круг «Без оттенка» показывает естественный цвет губ.

Кадры обрабатываются в браузере без записи и отправки. Кнопка «Выйти из примерки» отключает камеру и возвращает к предыдущему виду карточки с последним выбранным оттенком из первой палитры.

Камера доступна при открытии сайта по HTTPS или по локальному адресу на том же устройстве.
