# WebAR-лендинг для бренда косметики с визуализацией продукции

Курсовая работа по дисциплине «Разработка кроссплатформенных приложений дополненной реальности».

Федеральное государственное бюджетное образовательное учреждение высшего образования «МИРЭА – Российский технологический университет». Институт информационных технологий, кафедра игровой индустрии.

Посетитель открывает карточку помады «Мягкий цвет», выбирает оттенок и видит, как меняется цвет стика. Названия и цвета оттенков взяты из демонстрационного каталога учебной практики.

## Запуск

Открыть [лендинг на GitHub Pages](https://waitefy.github.io/cosmetics-webar/) в браузере телефона или компьютера.

Для локального запуска выполнить из корня проекта команды:

```sh
npm ci
npm run dev
```

Открыть [localhost:5173/cosmetics-webar/](http://localhost:5173/cosmetics-webar/).

## Стек

TypeScript, HTML и CSS. Vite запускает сервер разработки и собирает сайт. GitHub Actions проверяет типы, запускает сборку при обновлении ветки `main` и публикует результат на GitHub Pages.

## Состояние

Готовы карточка товара и выбор оттенка. Следующие этапы — вращаемая 3D-модель упаковки и примерка выбранного оттенка в дополненной реальности через фронтальную камеру.
