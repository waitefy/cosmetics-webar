# WebAR-лендинг косметики

Курсовая работа РТУ МИРЭА. Первый этап — карточка учебной помады «Мягкий цвет» и выбор оттенка. Стартовые названия и цвета взяты из демонстрационного каталога учебной практики.

## Локальный запуск

```sh
npm ci
npm run dev
```

Локальный адрес Vite — [localhost:5173/cosmetics-webar/](http://localhost:5173/cosmetics-webar/).

`npm run build` проверяет типы и собирает сайт в `dist/`. `npm run preview` запускает локальный просмотр сборки.

## Публикация

GitHub Actions собирает сайт при обновлении ветки `main` и публикует `dist/` на GitHub Pages. Источник публикации в настройках Pages — GitHub Actions.
